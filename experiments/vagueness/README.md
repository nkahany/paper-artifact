# Vagueness Ambiguity

Uses `vagueness.py` with zero-shot, one-shot, few-shot, and optional RAG modes.

Required data:
- `Vaguenes_fixed_req.csv`
- `vagueness_rag.csv`
- `srs_documents/` for RAG context

Run from this folder:

```bash
bash runall.sh
```

Expected reports from the uploaded runs are stored in `../../results/expected/vagueness/`.
